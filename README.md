# RECODE

**Revolutionizing engineer-to-order companies with deep learning and advanced recommendation systems for product design**

[![Funded by DFF](https://img.shields.io/badge/Funded%20by-Independent%20Research%20Fund%20Denmark-0ea5e9?style=flat-square)](https://dff.dk/en)
[![DTU](https://img.shields.io/badge/DTU-Technical%20University%20of%20Denmark-990000?style=flat-square)](https://www.dtu.dk)

## About

Engineer-to-order (ETO) companies design products tailored to each customer's requirements, which makes product design knowledge-intensive and time-consuming. RECODE develops deep learning methods and advanced recommendation systems to support product design decisions in ETO companies.

- **Principal Investigator:** [Sara Shafiee](https://github.com/sara-shaf), Technical University of Denmark (DTU)
- **Funding:** Independent Research Fund Denmark (DFF)
- **Host:** [Sara Shafiee Lab](https://github.com/Sara-Shafiee-lab), DTU

## Repository

This repository will host code, data resources, and documentation produced in the RECODE project. Contents will be added as the project's results are published.
